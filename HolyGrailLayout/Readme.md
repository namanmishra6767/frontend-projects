# Classic Holy Grail Layout

A simple implementation of the classic **Holy Grail Layout** using HTML and CSS.

The project demonstrates how to create a responsive page structure with a header, footer, main content area, left sidebar, and right sidebar.

## Preview

The layout follows this structure:

```text
┌─────────────────────────────────────────┐
│                 Header                  │
├─────────────┬───────────────┬───────────┤
│             │               │           │
│   Sidebar   │ Main Content  │  Sidebar  │
│             │               │           │
├─────────────┴───────────────┴───────────┤
│                 Footer                  │
└─────────────────────────────────────────┘
```

## Features

* Classic Holy Grail page structure
* Header and footer
* Left and right sidebars
* Flexible main content area
* Responsive layout
* Simple and clean CSS
* No external frameworks or libraries

## Technologies

* HTML5
* CSS3
* CSS Grid
* CSS Flexbox

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/holy-grail-layout.git
```

Open the project folder:

```bash
cd holy-grail-layout
```

Then open `index.html` in your browser.

No build tools or dependencies are required.

## Layout

The page is divided into five main sections:

* **Header**: Top navigation or branding area
* **Left Sidebar**: Secondary navigation or additional information
* **Main Content**: Primary page content
* **Right Sidebar**: Additional content, links, or widgets
* **Footer**: Bottom section containing additional information

## Purpose

This project was created to practice fundamental CSS layout techniques and understand how multiple page sections can be arranged using modern CSS.
